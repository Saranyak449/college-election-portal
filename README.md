🗳️ VoteFlow 2026

A modern, light, and secure web application for managing college elections.

✨ Features

Single Page Dashboard: Switch between Elections, Candidates, Voting, and Live Results instantly.

One Person, One Vote: Prevents duplicate voting using strict voter validation.

Real-time Vote Tally: View election results live as votes are cast.

Backend Connection Monitor: Shows real-time connection status to the Spring Boot server.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript

Backend: Java Spring Boot (REST API)

Database: PostgreSQL / MySQL

🚀 How to Run Locally

1. Backend (Spring Boot)

Open the backend folder in your IDE.

Run the application as a Spring Boot app (or run mvn spring-boot:run).

The server starts on http://localhost:8080.

2. Frontend

Open index.html in your web browser or use VS Code Live Server.

Make sure the badge at the top shows the backend is connected!
